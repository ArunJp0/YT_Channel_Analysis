# This project involves Exploratory Data Analysis (EDA) on multiple YouTube channels using the YouTube Data API.

# I used Python to perform:
  - Web scraping (via the YouTube Data API)
  - Data extraction and cleaning
  - Data transformation and analysis
  - Visualization of key performance metrics

# Key Insights Explored:
  - Subscriber count comparison
  - Total view count across channels
  - Number of uploaded videos
  - Top-performing videos by views, likes, and comments
  - Engagement metrics (likes per view, comments per view)

# Tools & Libraries Used:
  - Python
  - Pandas
  - Matplotlib
  - Seaborn
  - Google API Client

# Purpose:
  - To understand how YouTube channels perform in terms of reach, engagement, and content strategy through data-driven analysis.
